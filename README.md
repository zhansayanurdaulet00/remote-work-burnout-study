**Authors:** Nurdaulet Zhansaya, Kabygali Nazerke  
**Repository:** [https://github.com/zhansayanurdaulet00/remote-work-burnout-study](https://github.com/zhansayanurdaulet00/remote-work-burnout-study)

---

## Overview & Research Questions
This repository contains the empirical methodology, mock benchmark data, and statistical execution scripts for assessing how remote work boundary blurring impacts employee emotional burnout.

- **RQ1:** To what extent does work-life boundary blurring predict employee emotional exhaustion?
- **RQ2:** Do schedule autonomy and psychological detachment moderate the impact of remote work intensity on burnout?
